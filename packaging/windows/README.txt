Cadly — Windows x64 build (self-contained)

Run:
  bin\cadly.exe sample-files\as1-ug-214.stp          (GUI viewer)
  bin\cad_import_cli.exe sample-files\as1-ug-214.stp (headless import stats)

Requires Windows 10 or later and a GPU/driver with OpenGL 4.1+.
Qt, OCCT, and the GCC runtime DLLs are included. No MSYS2 installation or
separate compiler runtime installation is needed.
